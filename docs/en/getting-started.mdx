# Getting started

## Requirements

Node.js 20+, pnpm, Git, and a Supabase project. Never commit `.env`, service-role keys, JWT secrets, PayOS secrets, or SMTP passwords.

## Install

```bash
git clone https://github.com/minhduc290613/tech-ecommerce-store.git
cd tech-ecommerce-store
cp .env.example .env
pnpm install
```

All clone-time configuration is collected in `.env.example`; copy it to `.env` and edit the relevant values. The frontend reads `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`; backend/payment routes read `SUPABASE_URL` and server-only secrets. Do not edit `client/supabase-config.js` or commit `.env`. Then run `supabase-unified.sql` against a new or empty database.

```bash
pnpm dev
# open http://localhost:3000
```

## Release checks

```bash
pnpm test
pnpm check
pnpm build
```

Main entrypoints include the storefront, `/admin.html`, `/admin-en.html`, `/orders.html`, and `/affiliate.html`. Grant Admin access using [ADMIN_SETUP.md](../../ADMIN_SETUP.md); never use a default password.
