# Bắt đầu với NEXORA

## Yêu cầu

Node.js 20+, pnpm, Git và một project Supabase. Không commit `.env`, service role key, JWT secret, PayOS secret hoặc SMTP password.

## Cài đặt

```bash
git clone https://github.com/minhduc290613/tech-ecommerce-store.git
cd tech-ecommerce-store
cp .env.example .env
pnpm install
```

Mọi cấu hình cần thay khi clone nằm trong `.env.example`; copy thành `.env` rồi chỉnh các biến tương ứng. Frontend đọc `VITE_SUPABASE_URL` và `VITE_SUPABASE_ANON_KEY`; backend/payment đọc `SUPABASE_URL` và các secret server. Không sửa `client/supabase-config.js` và không commit `.env`. Sau đó chạy schema `supabase-unified.sql` trên database mới/trống.

```bash
pnpm dev
# mở http://localhost:3000
```

## Kiểm tra trước khi phát hành

```bash
pnpm test
pnpm check
pnpm build
```

Các entrypoint chính gồm storefront, `/admin.html`, `/admin-en.html`, `/orders.html` và `/affiliate.html`. Cấp quyền Admin theo [ADMIN_SETUP.md](../../ADMIN_SETUP.md), không dùng mật khẩu mặc định.
